# cs_training_tool_demo
# RSP Learner Demo

A static, interactive learner experience demo. It uses inline HTML, CSS, and JavaScript, so no build step or dependencies are required.

## Preview locally

Open `index.html` in a modern browser.

## Publish with GitHub Pages

1. Create a GitHub repository for the demo.
2. Upload `index.html` and this `README.md` to the repository root on the `main` branch.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. GitHub will show the public URL in **Settings → Pages**.

## Notes

- This is a front-end demo. It does not include a backend or persistent learner data.
- “Open live avatar” opens `https://avatar.eventplus.fun/` in a new tab; embedding and API integration are not part of this static demo.
- Do not place secrets, API keys, or private learner information in this public repository.
